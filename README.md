# FACEIT Player Form

Публичная страница Chrome-расширения, которое показывает форму игроков прямо в комнате FACEIT.

## Что показывает расширение

- общее количество матчей;
- матчи за 7, 30 и 180 дней;
- винрейт за 7 и 30 дней;
- средний FACEIT Rating за 7 и 30 дней;
- средние убийства и смерти в формате `18/15`;
- среднее количество матчей в день.

## Конфиденциальность

FACEIT Data API key хранится локально в Chrome и используется только для запросов к `open.faceit.com`.
У проекта нет собственного сервера или аналитики.

Этот проект не является официальным продуктом FACEIT.
